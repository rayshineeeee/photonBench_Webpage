PhotonBench

Do generative image models obey the laws of light?
Om Gole, Naima Hammad, Peter Choi, Ray Sun

Our render, then three ways a model could answer "add a red sphere": correct shadow, shadow in the wrong direction, no shadow.

Image models make pictures that look real. We test whether the light in them is physically right.

We render scenes with our CS184 path tracer, ask a model to edit them, then rebuild the model's output in 3D and render it ourselves to see what the light should have done.

How the benchmark works

1 · Render

Our project 3 path tracer renders a scene. A pass we added also writes depth, normals, object ids and shadow masks.

→
2 · Prompt the model
"Add a red sphere resting on the floor. Keep the camera, objects and lighting the same."

The image model gets our render and one specific instruction.

→
3 · Model output

The model may put the object anywhere and draw any shadow.

→
4 · Rebuild in 3D

We find the object, recover its 3D position, add it to our scene and render again.

→
5 · Score
GeometryDid the model keep the scene we gave it, or change it?
LightingDoes the shadow it drew match the one our render requires?

We grade against what the model drew, not one fixed answer image, so a misread prompt is not mistaken for bad physics. Project 3 alone outputs only a picture; the added outputs are the answer key that steps 4 and 5 need.
